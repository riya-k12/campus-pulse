# Smart Campus Incident Management

## 📌 About the Project
A centralized smart campus platform for managing campus incidents, resources, room allotments, and real-time notifications.

## 🚀 Features
- Incident Management
- Interactive Campus Map
- Allotment Schedule
- Quick Room Reassignment
- Resource Management
- Role-Based Access
- Real-Time Notifications
- Conflict Detection
- Analytics Dashboard

## 👥 User Roles
### Admin
Full system access.

### Staff / Teacher
Can manage incidents, resources and allotments.

### Student
Read-only access to schedules, room changes, campus map and announcements.

## 🛠️ Technologies Used
- React
- TypeScript
- Tailwind CSS
- JavaScript
- HTML
- CSS

## 🎯 Problem Solved
Campus information is often scattered across different communication channels. This platform centralizes incident reporting, room allocation, resource management and campus updates in one place.

## 🔄 Main Workflow
Incident Reported
→ Priority Identified
→ Resource Assigned
→ Problem Detected
→ Alternative Resource/Room Found
→ Allotment Updated
→ Users Notified
→ Incident Resolved

## 💻 How to Run
1. Clone the repository
2. Open the project folder
3. Install dependencies
4. Start the development server
5. Open the local URL in your browser
